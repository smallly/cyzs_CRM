#### CrudTable.vue (通用列表表格)
**位置:** [src/components/common/CrudTable.vue](src/components/common/CrudTable.vue)

**功能:**
- 统一列表表格布局(el-card + el-table)
- 支持列配置(prop/label/width/slot/formatter/tag类型)
- 支持分页(currentPage/pageSize/total/pageSizes)
- 支持排序(sortable/sortChange事件)
- 支持多选(showSelection/selectionChange事件)
- 支持操作列(showActions/edit/delete按钮)
- 支持加载状态(loading/v-loading)
- 支持固定列(fixed/右侧操作列)

**Props:**
```typescript
{
  title?: string              // 标题
  data: any[]                 // 数据源
  columns: TableColumn[]      // 列配置
  loading?: boolean           // 加载状态
  showSelection?: boolean     // 显示多选
  showAdd?: boolean           // 显示新增按钮
  showRefresh?: boolean       // 显示刷新按钮
  showEdit?: boolean          // 显示编辑按钮
  showDelete?: boolean        // 显示删除按钮
  showActions?: boolean       // 显示操作列
  showPagination?: boolean    // 显示分页
  total?: number              // 总条数
}
```

**Events:**
```typescript
{
  add: []                     // 新增
  refresh: []                 // 刷新
  edit: [row: any]            // 编辑
  delete: [row: any]          // 删除
  selectionChange: [rows]     // 多选变化
  sortChange: [sort]          // 排序变化
  pageChange: [page, size]    // 分页变化
}
```

**使用示例:**
```vue
<CrudTable
  title="联系人列表"
  :data="contacts"
  :columns="columns"
  :loading="loading"
  :show-add="true"
  :show-edit="true"
  :show-delete="true"
  @add="handleAdd"
  @edit="handleEdit"
  @delete="handleDelete"
>
  <template #status="{ row }">
    <el-tag :type="row.status === 'ENABLED' ? 'success' : 'danger'">
      {{ row.status }}
    </el-tag>
  </template>
</CrudTable>
```

#### FormDrawer.vue (通用表单抽屉)
**位置:** [src/components/common/FormDrawer.vue](src/components/common/FormDrawer.vue)

**功能:**
- 统一新增/编辑表单布局(el-drawer + el-form)
- 支持字段配置(prop/label/type/span/required/rules)
- 支持多种字段类型(input/number/select/date/time/switch/textarea/slot)
- 支持表单验证(el-form rules)
- 支持自定义插槽(type='slot')
- 支持加载状态(submitting)
- 支持宽度调整(size)

**Props:**
```typescript
{
  visible: boolean            // 显示状态
  title?: string              // 标题
  size?: number | string      // 宽度(默认50%)
  fields: FormField[]         // 字段配置
  modelValue?: any            // 表单数据
  rules?: FormRules           // 验证规则
  submitText?: string         // 提交按钮文本
  submitting?: boolean        // 提交加载状态
}
```

**Events:**
```typescript
{
  'update:visible': [value]   // 显示状态变化
  'update:modelValue': [value]// 表单数据变化
  submit: [form]              // 提交
  cancel: []                  // 取消
}
```

**使用示例:**
```vue
<FormDrawer
  v-model:visible="drawerVisible"
  title="新增联系人"
  :fields="formFields"
  v-model="formData"
  :rules="formRules"
  :submitting="submitting"
  @submit="handleSubmit"
>
  <template #customField="{ form }">
    <el-input v-model="form.custom" />
  </template>
</FormDrawer>
```

## 📝 改造策略总结

### 原视图改造模式

**Step 1: 状态管理改造**
```vue
<script setup>
// 从props改为内部状态
const users = ref<any[]>([])
const departments = ref<any[]>([])

// 从Pinia获取api
const authStore = useAuthStore()
const api = authStore.api

// 加载函数内部实现
async function loadUsers() {
  users.value = await authStore.api<any[]>('/api/users')
}
</script>
```

**Step 2: UI组件改造**
```vue
<template>
  <!-- el-card替换div.card -->
  <el-card>
    <!-- el-table替换table -->
    <el-table :data="users" border stripe>
      <!-- el-table-column定义列 -->
      <el-table-column prop="name" label="姓名" />
      <el-table-column label="状态">
        <template #default="{ row }">
          <!-- el-select替换select -->
          <el-select v-model="row.status" size="small">
            <el-option label="启用" value="ENABLED" />
          </el-select>
        </template>
      </el-table-column>
    </el-table>
  </el-card>
</template>
```

**Step 3: 交互改造**
```vue
<script setup>
// 原生alert改为ElMessage
ElMessage.success('更新成功')

// 原生confirm改为ElMessageBox
await ElMessageBox.confirm('确认删除吗?', '删除确认', {
  confirmButtonText: '删除',
  cancelButtonText: '取消',
  type: 'warning'
})
</script>
```
